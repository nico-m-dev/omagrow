# Open Crop Icons

The files in this folder come from [Open Crop Icons](https://github.com/openfarmcc/open-crop-icons),
a set of commonly cultivated crops by the OpenFarm community.

License: **CC0 1.0** (public domain). Attribution is not required, but the credit is kept here in
good spirit. The SVG files are unmodified apart from being bundled.

All 247 crop SVGs from the upstream set are included. They come from commit
`d41f1197a14bb82f12037dc47585152ae1e3074f` of the upstream repository.
